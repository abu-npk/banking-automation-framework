# Banking Automation Framework

Enterprise-grade banking automation framework built with Java 17, Selenium 4, TestNG, Maven, and Allure.

## Project Status

Project foundation established.

Framework components will be implemented incrementally following enterprise automation architecture and production coding standards.

## Technology Stack

- Java 17
- Selenium 4
- TestNG
- Maven
- Allure
- Log4j2
- Apache POI
- Jackson
- REST Assured
- JDBC

## Architecture Principles

- SOLID
- DRY
- Clean Code
- Separation of Concerns
- Page Object Model
- Thread-safe WebDriver management
- Data-driven testing
- Parallel execution
- Cross-browser execution
- CI/CD readiness

## Application Domain

Internet Banking application covering:

- Login
- Dashboard
- Accounts
- Transactions
- Fund Transfer
- NEFT
- RTGS
- IMPS
- Beneficiaries
- Statements
- Cards
- Loans
- Profile
- Settings
- OTP
- Confirmation
- Error handling

## Branch Strategy

The main branch contains stable project code.

Feature development will be performed using feature branches.
